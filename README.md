# Hermes — Personal Google Integration

This repository is the public branding home for a **private, single-user**
Google API application used by its owner (Kevin) to connect a personal,
self-hosted automation agent ("Hermes") to **his own** Google account.

- The application is **not a product** and is **not offered to the public**.
- It is authorized only by its owner, and only to access the owner's own
  Google data: Calendar, Drive, Sheets, Docs, and Contacts (read-only).
- There is no server, no backend service, and no third-party sharing:
  the OAuth tokens are stored locally on the owner's own machine.
