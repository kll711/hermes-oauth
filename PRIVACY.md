# Privacy Policy

_Last updated: October 2026_

## What this is

"Hermes" is a private, self-hosted automation agent operated by its owner
(Kevin) for personal use. The associated Google API application (Google Cloud
project `lucid-hook-505005-u1`) is used solely by the owner, solely to access
**the owner's own** Google account. It is not offered as a product or service
to any other person, and no other person can authorize it.

## What data is accessed

With the owner's explicit consent (OAuth), the application accesses only the
owner's own Google data:

- Google Calendar (events)
- Google Drive (files)
- Google Sheets (spreadsheets)
- Google Docs (documents)
- Google Contacts (read-only)

## How the data is used

Accessed data is used exclusively to perform personal automation tasks
requested by the owner on their own machine — e.g. reading a spreadsheet,
or organizing documents and calendar entries. No automated profiling, no
advertising, no analytics.

## How the data is stored and shared

- OAuth access tokens are stored locally on the owner's own machine and are
  never transmitted anywhere except to Google's API endpoints.
- Data is **not** sold, rented, shared, or transferred to any third party.
- There is no remote server or backend operated for this application.
- Data retrieved from Google is not used for advertising and is not used to
  train machine-learning models, and no humans besides the owner read it.

## Retention and deletion

- No Google user data is retained beyond local caches required to service the
  owner's own requests; those caches live on the owner's machine and can be
  deleted at any time.
- The owner can revoke the application's access at any time at
  https://myaccount.google.com/permissions, which immediately ends all access,
  or by deleting the locally stored OAuth tokens.

## Compliance

This application's use of Google user data adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.
